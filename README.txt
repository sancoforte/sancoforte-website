Before publishing:
1. Verify every ingredient amount against the current approved product pack. Vitamin K2-7 amount is deliberately shown as "See pack label" because the amount has appeared inconsistently in previous materials.
2. Verify business address and Amazon listing URL.
3. This is a starter site with a stylized text product mockup, not a photograph of the actual package.
4. The site is informational and does not collect visitor data or process purchases.

FREE PUBLISHING USING GITHUB PAGES:
1. Sign in to GitHub or create an account.
2. Create a new PUBLIC repository named sancoforte-website.
3. Upload index.html, style.css, and script.js to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for the published link, usually https://YOUR-USERNAME.github.io/sancoforte-website/

A free hosted subdomain may or may not be accepted by Amazon Ads; verify before relying on it for registration.
